# BGRecorder（バックグラウンド録画アプリ）

録画を続けたまま、ホーム画面に戻ったり他のアプリ・ブラウザを開いたりできる動画専用カメラアプリです。
フィルターは「通常」「暗所」「風景」の3種類、一時停止・再開ができ、マイクの音声も録音します。

**録画データはこのアプリの中には保存されません。閲覧専用の別アプリ「BGViewer」をセットで使う仕様です。**
詳しくは下の「BGViewerとの関係（重要）」を読んでください。

---

## BGViewerとの関係（重要）

このアップデートから、録画した動画は「アルバム」や他のギャラリーアプリ・ファイル管理アプリからは
**一切見えなくなりました**。録画データはBGRecorderの内部ストレージ（他のアプリからはroot無しでは
絶対に見えない領域）に保存され、唯一の閲覧手段は同梱の**BGViewer**という専用アプリだけです。

仕組み：
- BGRecorderは、同じ鍵（署名）で作られたアプリだけがアクセスできる「signature権限」を使ってデータを公開しています。
- BGViewerはBGRecorderと**全く同じkeystoreファイル**で署名してビルドするため、この権限を自動的に持てます。
- 逆に言うと、Gallery・他の動画プレイヤー・ファイル管理アプリなど、この鍵を持たないアプリは
  この権限を絶対に取得できず、一覧の取得もファイルを開くことも一切できません。

そのため、**BGRecorderとBGViewerは必ずセットでビルド・インストールしてください**（BGViewerだけ入れても
BGRecorderが無いと「BGRecorderが見つかりません」と表示されます）。

なお、このアップデートより前のバージョンで「アルバム」の`Movies/BGRecorder`に保存されていた過去の動画は、
次回録画時に自動的にアプリ内部（BGViewerからのみ見える場所）へ移動され、公開領域からは削除されます
（アプリを開いて1回録画するとこの移行が走ります）。

## 画質を保ったまま容量を圧縮

対応端末では動画をH.265(HEVC)で記録するようにしました。H.264よりも低いビットレートで同等の見た目の画質を
保てるため、体感画質はそのままにファイルサイズを抑えられます（非対応の古い端末では自動的にH.264にフォールバックします）。

## 正直にお伝えしたいこと（重要）

MyCameraと違い、今回はWebViewを使わず、Camera2 API・OpenGL・MediaCodecを直接組み合わせた
**本格的なネイティブAndroidコード**で作っています。バックグラウンドでの録画継続（フォアグラウンドサービス）や、
フィルターをかけながらの動画エンコードは、Web技術だけでは実現できないためです。

そのぶん、MyCameraよりもコードの複雑さが大きく上がっています。私の方でXMLファイルの構文チェックまでは
行っていますが、**実機での動作確認はできていません**。ビルド時にエラーが出る可能性はMyCameraのとき以上に
高いと考えてください。エラーが出たら、これまでと同じように`ERROR:`の行を教えてもらえれば直します。

## 既知の制限（アプリでは回避できないもの）

- **画面をロックする、または画面を消すと、Androidの仕組み上カメラへのアクセスがOSに強制的に止められ、
  録画が途切れます。** これはどのアプリでも回避できないAndroid自体の制限です。「他のアプリを開く」「ホーム画面に戻る」
  （＝画面はついたまま）は問題なく録画を継続できますが、「画面を消す・ロックする」は録画が止まると考えてください。
- 解像度は今回1080p固定にしています（MyCameraのような解像度選択は付けていません）。必要であれば後から追加できます。

## セットアップ手順（MyCameraのときと同じ流れです）

### 1. 新しいGitHubリポジトリを作る
`bgrecorder` などお好きな名前で、Public/Privateどちらでも構いません（Pages機能を使わないので今回はPrivateのままで大丈夫です）。

### 2. ファイルをアップロードする
お渡しするzipを展開すると `bgrecorder` フォルダが出てきます。**そのフォルダを開いて、中に入っている
`app`・`gradle`・`.github`・`keystore`・`build.gradle.kts`などを全部選択してから**アップロードしてください
（`bgrecorder`フォルダそのものをドラッグすると、前回と同じように1階層余計になってしまうので注意してください）。

`.github`フォルダが見えない場合は、パソコンの隠しフォルダ表示をオンにしてください。

- Mac: Finderで `Cmd + Shift + .`
- Windows: エクスプローラーの「表示」→「隠しファイル」にチェック

### 3. ビルドを待つ
「Actions」タブを開き、「Build APK」が自動的に走るのを待ちます（数分程度）。

### 4. APKをダウンロード・インストール
成功したら、実行結果の「Artifacts」欄から`BGRecorder-apk`をダウンロードし、スマホにインストールしてください。
初回起動時にカメラ・マイク・通知の権限を許可してください。

### 5. BGViewerも忘れずに
録画を見るには**BGViewer**アプリが別途必要です。お渡しした`bgviewer-android-project.zip`を、
このBGRecorderと同じ流れで別のGitHubリポジトリにアップロードしてビルドし、インストールしてください
（詳しくはBGViewer側のREADMEを参照）。

## 使い方

1. アプリを開くとカメラのプレビューが表示されます
2. 画面下でフィルター（通常／暗所／風景）を選ぶ
3. 「● 録画開始」をタップ
4. そのままホームボタンを押したり、他のアプリ・ブラウザを開いてOKです。通知欄に録画中の表示が出続けます
5. 一時停止したいときは、アプリに戻るか通知欄から「一時停止」
6. 録画を終えるときは、アプリに戻るか通知欄から「停止」。動画はアプリ内部に保存され、**BGViewerアプリを開くと一覧・再生できます**（「アルバム」等の他アプリには出てきません）
